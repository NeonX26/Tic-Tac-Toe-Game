# ❌⭕ Tic Tac Toe Game

A simple, browser-based **Tic Tac Toe** game built using **HTML**, **CSS**, and **JavaScript**. Playable by two players on the same device.


---

## 🎮 How to Play

- Player 1 is `X` and Player 2 is `O`
- Players take turns clicking on the grid to place their symbol
- The first player to align 3 symbols horizontally, vertically, or diagonally wins
- If all cells are filled with no winner, the game ends in a draw

- **CSS** – Styling and layout
- **JavaScript** – Game logic (turns, win detection, reset, etc.)
